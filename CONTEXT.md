# Ubiquitous Language

| Term | Meaning |
| --- | --- |
| Instrument | A tradable market symbol tracked by Market Eagle. |
| Sector | A canonical market grouping represented in the initial release by a sector ETF. |
| Daily Bar | One instrument's end-of-day OHLCV observation for a trading date. |
| Relationship | A calculated historical lead/lag association between two sectors over a stated window; it is not causal or predictive. |
| Analysis Run | An immutable calculation run that materializes relationships and evidence from the retained bars. |
| Brief | A dated, evidence-backed natural-language summary produced by the daily analyst workflow. |
| Research Session | One user question and the Temporal agent run, tool observations, and final answer used to answer it. |
